# Улучшенный профиль игрока

## Обзор

Улучшенный профиль игрока вдохновлен дизайном Lunda Padel и адаптирован для веб-версии. Включает визуальные компоненты для отображения прогресса рейтинга, статистики и эффективности игрока.

## Основные компоненты

### 1. Визуальный прогресс-бар рейтинга

**Горизонтальный градиентный бар** от D до PRO с индикатором текущей позиции:
- Цветовая схема: D (красный) → D+ (оранжевый) → C (желтый) → C+ (салатовый) → B (зеленый) → B+ (синий) → A (фиолетовый) → PRO (темный)
- Анимированный индикатор с tooltip
- Отображение текущего уровня и числового рейтинга
- Процент прогресса внутри текущего уровня

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 10-120)
- Шаблон: `templates/users/partials/enhanced_profile_overview.html` (строки 11-50)

### 2. Статистические карточки

Четыре основные карточки с ключевыми метриками:

1. **Турниры** - количество сыгранных турниров и побед
2. **Игры** - общее количество игр и активность за месяц
3. **Партнеры** - количество уникальных партнеров
4. **Победы** - количество побед и винрейт

Каждая карточка:
- Имеет уникальную иконку с градиентным фоном
- Отображает основное значение крупным шрифтом
- Показывает дополнительную статистику с трендом (↑/↓)
- Анимируется при наведении
- Кликабельна (переход к соответствующему разделу)

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 121-230)
- Шаблон: `templates/users/partials/enhanced_profile_overview.html` (строки 52-102)

### 3. Круговая диаграмма эффективности

**SVG-анимация** показывает общую эффективность игрока в процентах:
- Анимированная круговая диаграмма с градиентом
- Центральное значение с процентом
- Детальная разбивка по категориям:
  - Точность подач
  - Выигранные розыгрыши
  - Успешные удары

**Расчет эффективности:**
```python
efficiency = (rating / 7.0) * 50% + (активность / max) * 50%
```

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 231-340)
- Шаблон: `templates/users/partials/enhanced_profile_overview.html` (строки 104-146)
- JavaScript: встроен в шаблон (строки 218-250)

### 4. Предупреждающий баннер

Отображается, если рейтинг не подтвержден тренером:
- Желтый градиентный фон
- Иконка предупреждения
- Информативный текст

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 341-365)
- Шаблон: `templates/users/partials/enhanced_profile_overview.html` (строки 6-13)

### 5. Быстрые действия

Две карточки быстрого доступа:

1. **Мои бронирования** - показывает количество предстоящих броней
2. **Результаты** - показывает общую статистику или призыв создать игру

Обе карточки кликабельны и ведут к соответствующим вкладкам.

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 366-430)
- Шаблон: `templates/users/partials/enhanced_profile_overview.html` (строки 148-178)

### 6. Метаданные пользователя

Отображает дополнительную информацию:
- Город

- Дата регистрации
- Дата рождения (если указана)

**Файлы:**
- CSS: `static/css/enhanced-profile.css` (строки 520-580)

## Используемые данные

### Существующие поля модели

Из `PlayerRating`:
- `level` - буквенный уровень (D, D+, C, и т.д.)
- `numeric_rating` - числовой рейтинг (1.00 - 7.00)
- `get_progress_percentage()` - процент прогресса в уровне
- `updated_by` - кто обновил рейтинг
- `updated_at` - когда обновлен

### Новые метрики из `get_player_stats()`

Добавлены в `users/analytics.py`:

```python
{
    # Существующие
    'total_games': int,           # Общее количество игр
    'total_hours': float,         # Общее количество часов
    'games_per_week': float,      # Игр в неделю

    # Новые для улучшенного профиля
    'unique_partners': int,       # Уникальные партнеры
    'games_this_month': int,      # Игры в этом месяце
    'tournaments_played': int,    # Сыгранные турниры
    'tournaments_won': int,       # Выигранные турниры
    'wins': int,                  # Количество побед
    'win_rate': float,            # Процент побед
    'efficiency': float,          # Общая эффективность (0-100%)

    # Детальная статистика (пока заглушки)
    'serve_accuracy': float,      # Точность подач (%)
    'rallies_won': float,         # Выигранные розыгрыши (%)
    'successful_shots': float,    # Успешные удары (%)
}
```

## Анимации

### JavaScript анимации

1. **Индикатор рейтинга** - плавно перемещается к позиции, соответствующей текущему рейтингу
2. **Круговая диаграмма** - анимируется от 0% до целевого значения
3. **Счетчики статистики** - числа анимированно увеличиваются от 0 до целевого значения

### CSS анимации

1. **fadeInUp** - появление карточек снизу вверх
2. **Разная задержка** для каждой карточки (0.1s, 0.2s, 0.3s, 0.4s)
3. **Hover эффекты** - подъем и усиление тени при наведении

## Производительность

### Оптимизации запросов

Используется `select_related` и `prefetch_related` для минимизации количества запросов:

```python
user = User.objects.select_related('profile', 'rating').get(id=user_id)
```

### Кэширование

Можно добавить кэширование статистики:

```python
from django.core.cache import cache

cache_key = f'player_stats_{user.id}'
stats = cache.get(cache_key)

if not stats:
    stats = get_player_stats(user)
    cache.set(cache_key, stats, 300)  # 5 минут
```
