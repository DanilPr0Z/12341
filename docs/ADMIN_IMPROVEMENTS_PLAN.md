# План улучшений админ-панели на основе YClients CRM

## Дата: 2026-02-07

## Анализ YClients CRM

### Ключевые преимущества YClients:

1. **Продуманная навигационная структура**
   - Многоуровневое меню с группировкой функций
   - Collapsible секции для экономии пространства
   - Четкая иерархия: Обзор → Аналитика → Финансы → Специфичные функции

2. **Встроенный календарь в сайдбаре**
   - Быстрый доступ к датам
   - Визуальное выделение текущего дня
   - Навигация по месяцам

3. **Профессиональный дизайн**
   - Светлая цветовая схема с акцентами
   - Использование карточек и блоков с тенями
   - Консистентная типографика
   - Иконки FontAwesome для всех действий

4. **Функциональные элементы**
   - Настройки личного кабинета
   - Система уведомлений
   - Быстрые действия
   - Фильтры и поиск

**Текущая проблема:** Плоский список ссылок без группировки

**Решение:**
```
📊 Обзор
  ├─ Dashboard (сводка)
  ├─ Активность (activity log)
  └─ Уведомления

📅 Бронирования
  ├─ Расписание (календарь)
  ├─ Список бронирований
  └─ Создать игру

📈 Аналитика
  ├─ Основные показатели
  ├─ Финансовый отчет
  └─ Загруженность кортов

👥 Пользователи
  ├─ Все пользователи
  ├─ Рейтинги игроков
  └─ Тренеры

🏆 Турниры
  ├─ Список турниров
  ├─ Создать турнир
  └─ Архив

💰 Финансы
  ├─ Платежи
  ├─ Статистика доходов
  └─ Экспорт данных

⚙️ Настройки
  ├─ Корты
  ├─ Расписание работы
  ├─ Настройки системы
  └─ Профиль администратора
```

#### 5. **Система уведомлений** (Приоритет: MEDIUM)

**Функционал:**
- Icon с badge в header (колокольчик)
- Dropdown с последними уведомлениями
- Типы уведомлений:
  - Новое бронирование
  - Отмена бронирования
  - Новая регистрация
  - Новый платеж
  - Системные уведомления

**База данных:**
```python
# models.py в manager app
class Notification(models.Model):
    TYPES = [
        ('booking_new', 'Новое бронирование'),
        ('booking_cancelled', 'Отмена бронирования'),
        ('user_new', 'Новая регистрация'),
        ('payment_new', 'Новый платеж'),
        ('system', 'Системное'),
    ]

    type = models.CharField(max_length=20, choices=TYPES)
    title = models.CharField(max_length=200)
    message = models.TextField()
    link = models.URLField(blank=True)
    is_read = models.BooleanField(default=False)
    created_at = models.DateTimeField(auto_now_add=True)
    user = models.ForeignKey(User, on_delete=models.CASCADE, null=True, blank=True)
```
