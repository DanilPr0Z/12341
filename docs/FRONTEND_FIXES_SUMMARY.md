## 🧪 Тестирование

### Как протестировать:

1. **Запустить сервер:**
```bash
python manage.py runserver
```

2. **Проверить модалки:**
- Открыть http://localhost:8000/
- Кликнуть "Войти" → должна открыться зеленая модалка
- Кликнуть "Зарегистрироваться" → должна открыться модалка регистрации
- Закрыть крестиком → анимация закрытия

3. **Проверить Dashboard:**
- Открыть http://localhost:8000/manager/
- Должны быть:
  - 4 карточки с метриками
  - 2 графика (линейный и столбчатый)
  - Кнопки быстрых действий
  - Календарь в sidebar
  - Collapsible меню

4. **Проверить responsive:**
- Открыть DevTools → Toggle device toolbar
- Проверить на iPhone/iPad
- Sidebar должен скрываться на мобилке
- Модалки должны быть полноэкранными
